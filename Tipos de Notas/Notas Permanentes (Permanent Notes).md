> [!summary] Em uma frase
> A nota permanente é a unidade de valor real do Zettelkasten: uma ideia atômica, autônoma, escrita com suas próprias palavras, conectada à rede — feita para durar anos e ser reaproveitada em contextos que você nem imagina no momento de escrevê-la.

## As 4 propriedades obrigatórias

1. **Atômica** — uma ideia só. Ver [[Princípios Fundamentais do Zettelkasten]].
2. **Autônoma** — faz sentido sem abrir a fonte original.
3. **Título-frase** — o título é uma afirmação completa, não um rótulo. Compare:
   - Ruim: `Produtividade`
   - Bom: `Fricção na captura elimina ideias antes de serem avaliadas`
4. **Conectada** — pelo menos um link de saída (`[[para outra nota]]`) no momento da criação.

## Anatomia de uma boa nota permanente

```
# Título que é uma afirmação completa

Um ou dois parágrafos explicando a ideia com suas próprias palavras — 
como se você estivesse explicando para alguém inteligente que não tem 
o contexto da fonte original.

Se veio de algum lugar, cite a fonte no fim, não no início (a ideia 
vem primeiro, a atribuição é secundária).

## Ver também
- [[Nota relacionada 1]] — por que se conecta (não só o link solto)
- [[Nota relacionada 2]]
```

> [!tip] O link precisa de contexto
> `[[Notas Fugazes (Fleeting Notes)]]` sozinho no fim de uma lista diz *que* existe relação. Uma frase ao lado (`— fleeting notes são a matéria-prima descartável, esta nota é o produto final`) diz *qual* é a relação — e é isso que faz a rede ser navegável e não só "tecnicamente conectada".

## De onde nascem

- Reformulação de uma [[Notas de Literatura (Literature Notes)|nota de literatura]] (o caminho mais comum)
- Um insight direto, sem fonte externa — uma conexão que você percebeu sozinho entre duas notas já existentes
- Uma [[Notas Fugazes (Fleeting Notes)|fleeting note]] que, ao ser processada, se mostrou boa o suficiente para virar permanente

## Quando uma nota "cresce demais"

Se ao escrever você perceber que está defendendo duas afirmações diferentes, pare e divida em duas notas, cada uma linkando a outra. É comum uma nota permanente nascer grande e ser "podada" depois — isso é normal e saudável, não retrabalho perdido.
