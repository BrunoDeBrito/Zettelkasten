> [!summary] Em uma frase
> ACE divide o vault pelas **3 dimensões** de qualquer informação: **Atlas** (conhecimento, o espaço), **Calendar** (o tempo) e **Efforts** (a ação). É a alternativa ao PARA pensada para o Obsidian.

## As 3 pastas

### Atlas, conhecimento ("o que eu sei")
- `Atlas/Maps/`: os MOCs
- `Atlas/Dots/`: as notas de ideia (equivalente às notas permanentes)
- `Atlas/Sources/`: livros, artigos, cursos (equivalente às notas de literatura/recursos)

### Calendar, tempo ("quando aconteceu")
- `Calendar/Daily/`: daily notes
- `Calendar/Logs/`: reuniões, diários, registros com data

### Efforts, ação ("no que estou trabalhando")
Esforços divididos por **intensidade**, não por prazo:
- **On**: trabalhando ativamente agora
- **Ongoing**: contínuo, sem fim (parecido com Áreas)
- **Simmering**: em fogo baixo, avança de vez em quando
- **Sleeping**: parado, mas não abandonado

> [!info] Versão anterior: ACCESS
> Antes do ACE, o LYT usava o **ACCESS** (Atlas, Calendar, Cards, Extras, Sources, Spaces). O ACE é a simplificação dele. Se encontrar vaults ou vídeos com ACCESS, é a mesma família de ideias.

## ACE vs PARA
| PARA | ACE | Diferença |
|---|---|---|
| Projetos | Efforts / On | ACE não exige prazo |
| Áreas | Efforts / Ongoing | Igual |
| Recursos | Atlas | ACE separa mapas, ideias e fontes |
| Arquivo | Efforts / Sleeping (ou arquivo) | ACE prefere "dormindo" a "morto" |
| — | Calendar | PARA não tem lugar próprio para o tempo |

**Quando ACE é melhor:** se seu vault é mais de **estudo e conhecimento** do que de projetos com prazo.
**Quando PARA é melhor:** se você tem **muitos projetos com entrega** e quer usar a mesma estrutura no Drive, e-mail etc.

## Exemplo com as pastas deste vault
```
Atlas/
    Maps/          ← Zettelkasten.md, Design Pattern.md, MOCs novos
    Dots/          ← notas permanentes do Zettelkasten
    Sources/       ← Library and Highlights, Clippings, Courses
Calendar/
    Daily/         ← daily notes (hoje em 0 - Inbox)
    Logs/          ← Biblical Year, Sabbath School Lesson
Efforts/
    On/            ← JobApplication, vídeo atual do YouTube
    Ongoing/       ← Routine, YouTube Channel
    Simmering/     ← curso Pinguim Academy em ritmo lento
    Sleeping/      ← cursos pausados
```
